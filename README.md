# Наш лось!

Пиксельная игра. Защищённая тестовая сборка; пароль передаётся отдельно. Репозиторий содержит только зашифрованную игру и страницу доступа.

[Играть](https://starglader.github.io/space-moose/)

Статическая защита AES-256-GCM, не серверная авторизация. Подготовленные спрайты, ограниченный кэш, резервный путь без Worker. Расчёт нагрузки для слабых устройств выполнен; проверка на устройстве не требуется по заданию.
